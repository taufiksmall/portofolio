# Premium Portfolio

A premium personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide Icons.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

- `vite.config.js` uses `base: './'` so the build is safe for GitHub Pages and static hosting.
- The project also works on Vercel with the default Vite settings.

## Content

- Update projects in `src/data/projects.js`
- Update experience in `src/data/experience.js`
- Replace placeholder contact links and `public/cv.pdf` when ready
